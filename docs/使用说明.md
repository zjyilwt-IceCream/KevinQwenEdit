# KEVIN-QwenImage2.1 换头+姿势调整编辑整合流

发布版本：0.1.0，2026-09-29。

本说明可以独立阅读。配套 ZIP 仅含工作流 JSON 和本说明；节点到以下仓库自行安装，模型另行下载。主图片、头部图片需要使用者上传。

## 一、节点仓库与安装

| 项目与下载地址 | 在本工作流中的用途 | 安装目录 |
| --- | --- | --- |
| **[KevinQwenEdit](https://github.com/zjyilwt-IceCream/KevinQwenEdit)** | 本次新编写的输出尺寸、任务指令、可选头部输入、Fisher 桥接与姿势预览、模式开关控制 | `ComfyUI/custom_nodes/ComfyUI-KevinQwenEdit` |
| [ComfyUI-Fisher-Pose](https://github.com/Work-Fisher/ComfyUI-Fisher-Pose) | 三维人偶、姿势预设、姿势编辑页面 | `ComfyUI/custom_nodes/ComfyUI-Fisher-Pose` |
| [TE_MAN](https://github.com/tl2012tl/TE_MAN) | `TE_Qwen_Image_2_1_Prompt_Enhancer`、`TE_text_display` | `ComfyUI/custom_nodes/TE_MAN` |
| [ComfyUI-KJNodes](https://github.com/kijai/ComfyUI-KJNodes) | `SetNode` / `GetNode`，减少跨区连线 | `ComfyUI/custom_nodes/ComfyUI-KJNodes` |
| [rgthree-comfy](https://github.com/rgthree/rgthree-comfy) | `Image Comparer (rgthree)`，原图与结果对比 | `ComfyUI/custom_nodes/rgthree-comfy` |
| [ComfyUI](https://github.com/comfyanonymous/ComfyUI) | 图文编码、采样、VAE 与逻辑分支等核心功能 | 运行平台 |

在 `ComfyUI/custom_nodes` 目录打开终端，按缺失项目执行：

```bash
git clone https://github.com/zjyilwt-IceCream/KevinQwenEdit.git ComfyUI-KevinQwenEdit
git clone https://github.com/Work-Fisher/ComfyUI-Fisher-Pose.git ComfyUI-Fisher-Pose
git clone https://github.com/tl2012tl/TE_MAN.git TE_MAN
git clone https://github.com/kijai/ComfyUI-KJNodes.git ComfyUI-KJNodes
git clone https://github.com/rgthree/rgthree-comfy.git rgthree-comfy
```

已有节点就检查版本，不要再复制第二份。也可以从各仓库 Code → Download ZIP，解压到上述目录；Fisher 文件夹名称必须准确，因为本节点通过这个路径打开编辑器。安装 KevinQwenEdit 时，`__init__.py` 必须位于 `ComfyUI-KevinQwenEdit` 第一层。

如果以前使用随工作流附带的 KevinQwenEdit 旧副本，先将旧文件夹备份到 `custom_nodes` 外，再用 Git 安装新版本。不要把新旧两份同时放在 `custom_nodes` 里。

本节点的 Python 依赖为 ComfyUI 已有的 PyTorch、NumPy、Pillow。如缺少 NumPy/Pillow，用运行 ComfyUI 的同一个 Python 安装 KevinQwenEdit 仓库的 `requirements.txt`。其他节点依赖以各自 README 为准，避免用系统 Python 安装到另一套环境。

### 环境要求

- ComfyUI 必须具备 **`TextEncodeQwenImage21` 和 `ComfySwitchNode`**。这两个是核心节点，缺失时应更新 ComfyUI。
- 本流程实际验证环境：Windows、Python 3.12.10、RTX 4090 Laptop 16GB、64GB 内存。
- TE_MAN 当前 README 说明支持 Python 3.12/3.13，仓库发布内容含 Windows `.pyd`。Linux/macOS 用户应先向上游确认可用版本；完整流程尚未在这些系统验证。
- Fisher 的 `web/vnccs/assets/pose_studio_makehuman.v2.bin` 必须完整，约 86MB。只下到 Git LFS 指针或缺少此文件会导致人偶无法显示。
- `TE-Speed-QwenImage21` 不在这份工作流的节点清单中，不需要仅为本流程安装。
- 即使 PE 开关关闭，也建议完整安装 TE_MAN：工作流保留 PE 节点定义，而且最终提示词显示使用它的文本节点。PE 关闭可以不加载 PE 权重。

安装完成后重启 ComfyUI，并刷新浏览器。

## 三、导入与基本使用

把同包的 `KEVIN-QwenImage2.1 换头+姿势调整编辑整合流.json` 拖到 ComfyUI 页面；也可以存到 `ComfyUI/user/default/workflows/` 后打开。工作流里的操作注释与尺寸说明已保留。

1. 在“主图片”上传待编辑图片，在模型区核对模型选择。
2. 在左上角填写编辑要求，例如“保留人物身份和服装，把背景改成明亮的浅灰摄影棚，柔和自然光”。
3. 根据需求选择换头、姿势、PE 三个独立开关。
4. 检查输出尺寸，点击运行。成图保存到 `ComfyUI/output/KEVIN-QwenImage2.1-换头姿势/`。

分享版清除了测试图片路径、临时对比预览和上次输出的提示词，保留可编辑的人偶状态。上传自己的素材后才能生成。

### 换头与姿势开关

| 换头 | 姿势 | 要准备什么 | 实际执行 |
| --- | --- | --- | --- |
| 关闭 | 关闭 | 主图片、编辑要求 | 普通图片编辑 |
| 开启 | 关闭 | 主图片、头部参考 | BFS 换头；主图提供身体、场景和构图，头部图提供身份等头部特征 |
| 关闭 | 开启 | 主图片、已应用的人偶姿势 | 使用人偶作为姿势参考，保留主图人物外观和服装 |
| 开启 | 开启 | 主图片、头部参考、已应用的人偶姿势 | 先调整姿势，再在结果上换头，自动两轮采样 |

换头关闭时，换头区域节点变暗是正常的自动停用状态，头部参考可以不填。姿势关闭时不会执行人偶编码。无需逐个屏蔽节点或改线。

普通编辑在 PE 关闭时直接使用用户原文；换头与姿势模式会额外保留必需的任务前缀，以明确参考图角色。双开时，补充编辑要求先在姿势阶段处理，第二阶段负责换头。

### 人偶编辑与节点预览

点“打开自由姿势编辑器”，选择预设或拖动人偶，检查位置、关节、手势与画幅，然后点 **“应用到节点”**。

- 应用后，节点直接显示本次人偶姿势图，不需要先运行生成。
- 保存工作流再打开时，从 `pose_json` 内嵌截图恢复预览。
- 预览文件仅上传到当前 ComfyUI 的 `temp`，不会上传到外部服务。清理 `temp` 后，重新打开工作流会恢复。
- 点关闭或按 Esc 退出编辑器不等于应用修改。
- 编辑器补充要求会与主提示词同步。
- 人偶预览是姿势参考，不是最终人物成图。目前验证的是单人姿势。

## 四、输出尺寸

“输出尺寸”节点负责最终画幅，头部参考的宽高不决定结果尺寸。

- `custom_size` 关闭：按主图比例，以 `short_side` 设置短边，默认 **1024**。主图 2:3 时输出 **1024×1536**。
- `custom_size` 开启：按 `width` 与 `height` 指定宽高，例如 **1280×1024**。
- 实际宽高四舍五入对齐 32 像素，所以极端比例可能有轻微变化；以“实际输出尺寸”显示为准。
- 自定义比例不同于主图时，会完整缩放主图并补白，模型据此生成新画布。
- 改变画幅后重新打开姿势编辑器，检查人偶是否完整在橙色框内，再应用一次。

默认采用 25 步、CFG 1、Euler / simple、LoRA 强度 1，未叠加 Pruna 加速 LoRA。双开耗时会增加；16GB 显存用户可先从默认尺寸开始，更高像素需结合显存与内存实际情况调整。

## 五、PE 提示词增强

开关关闭时不执行增强器，也不加载其权重。开启时，PE 读取当前阶段图片和提示词，再把改写文本自动交给生成模型。

- **本地官方PE**：任务模式选择“图生图”，设置官方 I2I PE 权重。这是预选方式。
- **本地**：选择兼容的 GGUF 视觉模型及对应 mmproj，不是任意聊天模型都支持看图。
- 两阶段同时开启时，换头阶段会同步左侧 PE 设置，不需要设置两遍。
- “本次实际使用的最终提示词”显示最后一个阶段实际送给模型的内容。
- API 是上游 TE_MAN 保留的可选功能。此工作流没有填写密钥、地址或远程模型，不需要付费 API；如自行切换 API，应先明确服务与费用。

## 六、常见问题

| 现象 | 检查方法 |
| --- | --- |
| 缺少 `KevinQwen*` 节点 | 安装本说明第一行 KevinQwenEdit 仓库，检查目录层级，重启 ComfyUI |
| 缺少 `TextEncodeQwenImage21` / `ComfySwitchNode` | 更新 ComfyUI 核心及其依赖 |
| 找不到 PE 或文本显示节点 | 按 TE_MAN 文档核对平台、Python 版本和启动导入日志 |
| 姿势编辑器空白 / 404 | Fisher 文件夹必须为 `ComfyUI-Fisher-Pose`；确认其 editor 页面及约 86MB 人偶资产完整 |
| 应用后没有预览 | 更新 KevinQwenEdit、刷新页面，再应用；检查浏览器和 ComfyUI 日志中是否有本地 `/upload/image` 错误 |
| 预览被说明框遮住 | 使用本仓库新版工作流；旧图中可把说明框下移，为姿势节点留出高度 |
| 运行提示先应用姿势 | 在编辑器中点“应用到节点”，再保存工作流 |
| 模型显示 `Value not in list` | 检查目录，刷新模型列表，在下拉框重选实际文件；尤其注意官方 PE 新增 `_9b` 的文件名 |
| 关闭开关却仍执行对应部分 | 确认前端扩展加载成功，完整刷新；不要删除工作流的角色属性或只复制布尔开关 |
| 显存不足 | 降低短边或自定义像素，关闭暂时不需要的 PE，保持 PE“生成后自动卸载模型”开启；检查是否有其他 GPU 任务 |
